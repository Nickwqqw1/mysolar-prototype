# MySolar — frontend-прототип

Пять отдельных страниц на болгарском языке: Начало, Соларни решения, Соларен калкулатор, Как работим, Контакти и заявка. HTML, CSS, JavaScript; без сборки, сервера приложений, базы данных и платежей.

## Открыть на компьютере

Распакуйте весь архив `mysolar.zip` и откройте `mysolar/index.html` двойным щелчком. Сохраняйте структуру папок. Картинки и шрифты локальные; интернет нужен только при переходе на внешнюю карту или PVGIS.

Для локального сервера откройте терминал в папке `mysolar` и выполните:

    python -m http.server 8766 --bind 127.0.0.1

Адрес: http://127.0.0.1:8766 . Этот адрес доступен только на данном компьютере. Python не нужен для открытия через index.html.

## Посмотреть на iPhone

Надёжный вариант для Safari и друзей — HTTPS-ссылка после публикации. HTML-вложения на iPhone могут открываться в просмотрщике, который не запускает JavaScript.

Без публикации можно использовать одну домашнюю Wi-Fi-сеть: запустить `python -m http.server 8766 --bind 0.0.0.0` на компьютере, узнать IPv4 через `ipconfig`, открыть на iPhone `http://IP-КОМПЬЮТЕРА:8766`. При необходимости разрешить Python в брандмауэре для частной сети. Компьютер должен оставаться включённым. Не открывайте этот сервер в интернет.

## Бесплатная публикация без публичного репозитория GitHub

По разрешению владельца опубликован на GitHub Pages: https://nickwqqw1.github.io/mysolar-prototype/ . 11 октября 2026 года проверены публичный HTTPS-адрес, пять страниц и калькулятор. Репозиторий https://github.com/Nickwqqw1/mysolar-prototype публичный и виден в профиле GitHub. Ниже сохранена инструкция альтернативного размещения без публичного репозитория.

Cloudflare Pages поддерживает прямую загрузку статических файлов без GitHub. В аккаунте Cloudflare откройте Workers & Pages → Create application → Pages → Upload assets; названия пунктов могут меняться. Задайте имя проекта, загрузите содержимое папки `mysolar` так, чтобы index.html был в корне публикации, и выполните Deploy. Для прямой загрузки достаточно файлов сайта: пяти HTML, styles.css, app.js и assets/. После публикации проверьте выданный HTTPS-адрес, переходы и калькулятор на компьютере и iPhone.

Документация: https://developers.cloudflare.com/pages/get-started/direct-upload/ . Бесплатный тариф: https://developers.cloudflare.com/pages/platform/limits/ . Адрес, доступный по ссылке, не является паролем или закрытым доступом. Публикация не обязана появляться в профиле GitHub.

Альтернатива — GitHub Pages. На GitHub Free для этого нужен публичный репозиторий, который будет виден в профиле. На платных подходящих тарифах возможно размещение из приватного репозитория. Публикацию в GitHub сейчас не выполняли.

## Модель калькулятора

Все коэффициенты демонстрационные, не рыночные данные и не индивидуальная инженерная рекомендация.

- Добив: 1300 kWh/kWp в год, одинаковый для всех городов.
- Панель: 0,45 kWp, площадь 2,2 m² без проходов и отступов.
- Ценовой сценарий: 1200 €/kWp; примерная батарея 5 kWh добавляет 3500 €. Это модель комплектации, не полный монтаж и не оферта.
- Количество панелей: округлённый вниз минимум ограничений годового потребления, площади и бюджета после вычета батареи.
- Доля собственного потребления: дом 40%/65%, бизнес 65%/80%, без/с батареей. Почасовая работа батареи, её потери и реальный профиль нагрузки не моделируются.
- Собственная энергия ограничена годовым потреблением. Экономия = собственная энергия × 0,18 €/kWh; 0,18 — условный избегнутый тариф.
- Нет дохода от экспорта, срока окупаемости, обещаний резервного питания или гарантированной экономии.

Источники для реальной оценки: PVGIS https://joint-research-centre.ec.europa.eu/photovoltaic-geographical-information-system-pvgis_en и техническое обследование.

## Данные заявки

Форма проверяет имя, email, телефон, потребление и обязательное подтверждение демонстрационного характера. После проверки показывает «Демонстрационна заявка — данните не са изпратени» и очищает поля. Нет fetch, аналитики, cookies, localStorage, sessionStorage или сторонней отправки формы. Контактный email использует зарезервированный домен .example; адрес в Варне — пример района, не реальный офис. Открытие внешней карты/PVGIS происходит только по ссылке пользователя.

## Проверка

Проверены переходы, выбор каталога с батареей, перенос выбранного решения в заявку, калькулятор с/без батареи, бюджет ниже стоимости конфигурации, запрет нулевого бюджета, обязательные поля и успешное очищение формы. Проверка адаптивности проводится в браузере для desktop, планшета и 393 × 852 (размер iPhone 15 Pro). Это не тест на физическом iPhone или в настоящем Safari.

Базовая доступность: нативные формы и details, связанные подписи, управление меню с клавиатуры/Escape, фокус, живое сообщение результата, текстовая альтернатива графика, reduced motion. SEO: уникальные заголовки страниц, description, lang=bg, иерархия заголовков. Полный SEO-анализ и аудит доступности не проводились.

## Будущая WordPress-версия

Сделать собственную тему: общие header/footer, пять шаблонов страниц, подключение стилей и JS через enqueue, редактируемые блоки текста и карточек, настоящие URL меню и заявки. При добавлении реальных заявок — серверная валидация, защита от спама, согласованная обработка персональных данных, сроки хранения и реальная интеграция. Инженерный расчёт и поставщицкие цены разработать отдельно. Прототип служит визуальным референсом для самостоятельной реализации курсовой.
